# The Little Shah's Grand Adventure

A mobile-first baby shower celebration website for Lady Shah and Baby Shah. Live predictions, blessings from family in India, and letters to the baby.

## Features
- Adventure passport with six questions and aggregate live results
- Family blessing wall; multilingual messages supported
- Letters to Baby Shah
- Big-screen blessing presentation mode: footer > Presentation mode, or `/#host` (arrow keys navigate)
- Supabase-backed persistence; no signup required

## Hosting
Static website deployed to Vercel project `poohri-baby-shower`.

## Privacy / event operations
Content is shared with anyone who visits the site. Avoid posting private family information. No media uploads are implemented. Submission flow is open to visitors, so a host should monitor content. Browser identity is a convenience, not authentication. The baby shower rituals should be confirmed with family elders.

## Next improvements
Private invite access, administrator approval/moderation before publishing, curated slide ordering, photo/audio blessings, QR code, print-ready time capsule, stronger rate limiting and anti-spam.
